# SA U9 Inline Nationals 2026

Mobile-first Progressive Web App (PWA) for the SA U9 Inline Hockey team at the 2026 Australian National Championships.

## What families see
- Home: countdown, next game and latest updates
- Team: family-safe team roster
- Schedule: SA U9 round robin + conditional finals pathway
- Checklist: key Nationals requirements
- Info: useful links, venue and quick rules

## Privacy
Do **not** add private parent contacts, payment status, registration status, medical information or internal Team Manager notes to this public repository.

## Easiest way to update the app
Most ongoing content is in **`app-data.js`**. Edit that file to change:
- latest updates
- team names/roles
- schedule
- checklist
- useful links

The layout/design files normally do not need to be touched.

## Publish with GitHub Pages
1. Upload all files and the `icons` folder to the repository root.
2. In GitHub: **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Branch: **main** and folder: **/(root)**.
5. Save.
6. GitHub will provide the live Pages URL after deployment.

## Add to iPhone Home Screen
Open the live site in Safari → Share → **Add to Home Screen**.

## Schedule source
Initial schedule content is based on `Nationals 2026 Draw v2.6.xlsx` supplied to the Team Manager. All displayed times are Queensland time (AEST).
