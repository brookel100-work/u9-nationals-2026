# SA U9 Nationals 2026 — V9

V9 improves the Home → Team Announcements layout for mobile readability.

## V9 changes
- Breaks **Final Nationals Actions** into five clearly separated sections: Medical Forms, SIA Training, Team Checklist, Nationals Payments and Wine Raffle.
- Gold section headings, icons, spacing and subtle dividers make the announcement easier to scan on a phone.
- Existing upload/checklist action buttons remain directly beneath the announcement.
- **Share to U9 Messenger** now shares the same structured announcement rather than the old dense paragraph.
- Existing **Info → Documents** links remain unchanged and permanently accessible.
- Cache/query versions bumped to V9 to help devices pick up the update.

## Privacy note
This is a public GitHub Pages app. The Google URLs are visible to anyone who can access the app; Google Drive/Sheets permissions must be configured appropriately, particularly for medical documents.
