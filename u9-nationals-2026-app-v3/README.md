# SA U9 Inline Nationals 2026 — Team Hub v3

Mobile-first PWA for the South Australia U9 Inline Hockey team at the 2026 Australian National Championships.

## v3 changes
- SA-first red/navy/gold visual identity using the supplied SA team artwork
- SA Inline Hockey Club puck used as app icon/brand mark
- Removed manually maintained "Latest Team Updates"
- Added embedded Official Nationals Facebook timeline attempt with direct-page fallback
- Corrected U9 draw from Nationals Draw v2.6
- Training moved into a collapsed completed-history section
- Official Nationals branding remains in the event/info area

## Facebook feed note
Facebook controls whether its Page Plugin renders successfully in a browser. The app attempts to embed the timeline and always provides a direct link fallback. The current source supplied is a Facebook share URL; if Facebook requires the canonical Page URL, update `meta.facebookShareUrl` in `app-data.js`.

## Privacy
Do not add private parent contacts, payment status, medical information or internal Team Manager notes to this public repository.
